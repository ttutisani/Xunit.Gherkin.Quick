# Release 4.6.0

## Enhancements
- Language support: feature files can be localized to languages other than English (the framework recognizes keywords in all supported languages).
The issue can be found [here](https://github.com/ttutisani/Xunit.Gherkin.Quick/issues/96). Additional documentation can be found [here](/docs/language-support.md).

## Backward Compatibility

This release is backward compatible except for the places where you had a language other than English specified in your feature files. Such situations are considered incorrect use of the feature file, and failure therefore is by design. To fix these feature files, you need to either change the language code to English (because your feature text must have been in English), or fix the feature text (specifically, keywords) to be in the specified language (now your desired language must work).
